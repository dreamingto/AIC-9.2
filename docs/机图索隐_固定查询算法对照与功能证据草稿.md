## 查询与语料

固定24条查询：16文本、4整图区图片、4局部区域。主题包含图题/AI场景名、功能、结构与一条域外查询。
语料仅取锁定manifest的12幅国内真实古籍图，使用数据库中的50条兼容512维模型向量，排除9幅合成图。
《耕织图》为国内出版来源，《天工开物》为国图馆藏来源；Commons是扫描获取渠道。

查询在本轮第一次对照前写入协议，执行后未依据结果调整。既有的织机与宽泛水力演示查询此前已有观察，
因此整个协议属于开发集，不能称为独立测试集。所有 `relevance_labels=null`，没有qrels。
视觉输入来自语料扫描裁剪，所有方法排除来源图；没有给图片补写文字以使纯文本方法参加比较。

## 8种方法

|方法|实际输入和评分|适用查询|
|---|---|---|
|bm25|中文字符/片段BM25；以本查询最大分数归一|16文本|
|bge|BGE query/document余弦，仅比较BGE空间|16文本|
|chinese_clip|CLIP中文文本或视觉query对整图的共享空间余弦|全部24|
|hybrid|生产sv/st/sr系数，st=0.7BGE+0.3BM25；视觉输入的st来自CLIP图文空间|全部24|
|hybrid_no_region|与hybrid同系数，去掉sr，保留其它项|全部24|
|eafr_current|当前生产证据评分；区域查询沿用全来源文字主张|全部24|
|eafr_drafts|相同融合系数，叠加独立AI草稿的功能Jaccard及配对功能证据覆盖|全部24|
|eafr_drafts_no_evidence|保留功能项，去掉功能证据项|全部24|

BGE和CLIP即使维度相同也不混算。BM25/BGE对8条视觉查询分别标记 `not_applicable`。
hybrid移除功能/图谱/证据/不确定性系数；消融不重新调参，不宣称最优权重。
原生产API仍使用已有配置；新草稿通过实验工具参与对照，尚未接入默认线上排序。

## 功能与关系证据

四幅图属于两个既有案例：室内织机、大型织机、水碓、水磨。
共24个槽位，20个非unknown草稿、4个unknown，以及10条关系草稿。

每条已知功能都绑定本图扫描区域，部分附已有AI描述或AI图题转录的精确引用。
绑定器检查所属图、引用内容、文本来源类型、页面位置、扫描哈希、来源URL、原PDF哈希及许可。
目前没有可靠的古文正文功能引文；AI场景描述不会显示为古籍原文或人工校订。
织机运动和具体传动槽保留unknown；水力、旋转、舂捣等动态解释保持Inferred。

功能和关系的 `confidence=null`。实验功能可靠性固定0.5，是公开的工程政策，
不是模型概率或历史可信度。功能相似度使用已知槽/概念的Jaccard；证据项只计算当前查询功能
与候选有指针草稿的覆盖，匹配强度乘0.5，不按正文长度奖励。
无查询功能则证据不可用，纯图片不生成CFR；区域查询仅保留全部空间依据落在框内的草稿。
例如水轮局部不会继承另一侧碓臼的舂捣或谷物加工解释。

关系全部 `eligible_for_graph_rerank=false`。没有独立高置信度依据，sg不参与重排；
不将null置信度转换成熵或确定性，u_model不可用。已知功能仍是AI草稿，非独立标签。

## 本轮真实观察

176组适用查询/方法组合，另16组不适用；每组实际执行一次并重复两次，共528次排名计算。
最终运行均无失败、重复的完整排序/分数/分项签名稳定；向量与候选均从实际PostgreSQL读取。
与上一次完整运行逐项比较，176组完整排序/分数/分项签名也相同。

|---|---|---|---|
|织机 经线|室内织机、大型织机、室外整经|同左|已有顺序保持|
|水轮 驱动 谷物 加工|土礱、水碓、水磨|水碓、水磨、土礱|带指针的水力功能草稿使排序变化|

这是变化次数，不是改善率。尤其整经案例显示了不均匀标注的偏移，不能只挑水力结果宣称提升。
域外查询仍可能返回图，当前没有可靠的相关性拒绝阈值。

耗时分开记录 `feature_ms/ranking_ms/latency_ms` 及预热重复样本。
计时包含本方法需要的查询编码和排序，不含一次性数据库/候选载入、来源哈希验证、
HTTP请求及业务持久化。模型实验前已经加载，first-pass不是模型冷启动；数字不是生产P95。
全部实测时间和各查询前K分项见原始报告。

## 运行

先保证PostgreSQL中已经导入锁定真实manifest并建立神经索引，模型服务ready/cuda。
本机启动与模型下载说明见[真实模型与固定案例](机图索隐_真实检索模型与固定案例.md)。

在项目根目录执行：

```powershell
.\backend\model_runtime\start.ps1
Push-Location backend
try {
  .\.venv\Scripts\python.exe -X utf8 -m scripts.run_domestic_comparison
} finally {
  Pop-Location
}
```

程序输出本次报告目录和输入指纹。默认产物位于
`backend/data/real_pilot/retrieval_comparison/<input-fingerprint>/<UTC-run-id>/`。
每次都核验查询绑定的manifest SHA-256、扫描文件、数据库文本/状态/证据/版本来源和兼容向量。
原图/文本或索引不匹配时明确拒绝，没有静默基线回退或旧报告替换。
数据库事务为 `REPEATABLE READ, READ ONLY`，实际检查只读状态并回滚；不创建SearchSession。
