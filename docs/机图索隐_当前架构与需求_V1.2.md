# 当前架构与需求 V1.2

日期2026-10-05。本页为当前实现基准；策划/需求/技术长文的V1基线与历史增量供追踪。

目标：面向AIC智能文化比赛，以国内出版/馆藏古籍机械图为对象，提供带来源与解释边界的候选发现。文字、整图、局部区域查找候选，打开扫描、文本、来源和分项；核验按用户意愿持久化。机器推断不构成史实或传承判定。

## 已实现

- PostgreSQL16/pgvector、0001/0002迁移、稳定UUID导入和搜索快照。
- 合成/AI辅助/人审manifest分开，路径/许可/来源哈希、PNG及OCR链校验。
- 12真实图/14区域/35文本、两个国内固定案例；另9合成图用于工程验证。
- BGE/CLIP512维与256维基线，完整模型身份/预处理空间匹配，精确检索。
- PaddleOCR raw及独立环境；raw/corrected修改轨迹，当前真实corrected0。
- EAFR环境权重配置、空间主张范围、分项/缺失度/不确定性保存。
- React19/TypeScript/Zod、请求中止与竞态隔离；17个API操作。
- CI、独立PG集成、OpenAPI与Zod字段漂移检查、安全数据包/向量恢复。
- V2固定24查询/8方法，12图72槽草稿/unknown，10关系不参与图重排。

## 数据与实验边界

国内出版《耕织图》8图，国图馆藏《天工开物》4图；Commons是获取渠道。AI文本/图题/功能Inferred，扫描Observed，目录Documented。24查询是开发集，无独立qrels；研究指标not_evaluated。

真实线上功能/关系0，相应分项不可用。实验草稿只用于独立对照，不称默认API行为。权重默认工程政策；功能可靠性0.5非概率，confidence=null不制造伪熵。

## 架构与运行

浏览器 -> Nginx -> FastAPI -> 检索/导入/目录服务 -> PostgreSQL/pgvector。FastAPI通过宿主worker编码，worker启动校验模型锁、只读本地文件。OCR环境独立。

scripts/start.ps1的fixture/real/neural分别启动三种模式；真实版先恢复release数据包、导入manifest及冻结向量。独立复现使用release/compose.repro.yml和独立空卷，不复用业务库。

## 后续研究范围

独立人工真值、OCR/检索准确率、书籍/版本分离评测、专家研究验证；学习型CFR/关系抽取、来源可靠性校准、拒绝阈值、古籍微调；ANN、账户与多人生产部署。

这些研究缺口不通过把AI标签称为人工解决。按用户当前决定，比赛阶段不追加人工前置流程。
